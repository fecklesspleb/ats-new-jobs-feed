# n8n: daily new jobs from company career boards to a CSV file

An n8n workflow that runs once a day, asks the [ATS Jobs Scraper](https://apify.com/fecklesspleb/ats-jobs-scraper) Actor on Apify for jobs it has not returned before, skips any Job ID the workflow has already saved, and writes the new jobs to a dated CSV file. Disclosure: I (fecklesspleb) built this template and the Actor it calls; the Actor is paid per job.

File: `ats-new-jobs-to-csv.n8n.json` (import it with **Workflows > Import from file**). It is generated by `build.py`.

## Flow

1. **Every morning at 8** (Schedule Trigger).
2. **Search settings** (Edit Fields): `companies`, `keywords`, `stateStoreName`, `maxUsd`, `outputFolder`.
3. **Run ATS Jobs Scraper** (HTTP Request): `POST https://api.apify.com/v2/actors/fecklesspleb~ats-jobs-scraper/run-sync-get-dataset-items?maxTotalChargeUsd=<maxUsd>&timeout=280&clean=true` with the body `{companies, keywords, onlyNewJobs: true, stateStoreName, includeDescription: false, maxTotalJobs: 500}`. The response is a JSON array, which n8n turns into one item per record.
4. **Keep job records** (Filter): drops the Actor's free non-job records (boards that could not be resolved, status messages) and keeps records with a `uid` and `url`.
5. **Shape job row** (Edit Fields): Job ID, Company, Title, Location, Work arrangement, Posted, Salary, URL, ATS, First seen.
6. **Skip jobs already saved** (Remove Duplicates, "Remove Items Processed in Previous Executions", scope Workflow, keyed on Job ID, history 10,000 IDs): a second guard on top of the Actor's `onlyNewJobs`. n8n keeps the seen IDs in its own database (`processed_data` table), so they survive restarts.
7. **Convert to CSV** (Convert to File, CSV with a header row; n8n writes UTF-8 with a BOM, which Excel reads correctly).
8. **Write CSV file** (Read/Write Files from Disk): `<outputFolder>/new_jobs_YYYY-MM-DD_HHmmss.csv`. A run with no new jobs writes no file.

It uses only built-in n8n nodes and needs only one credential (the Apify token). There is no Google Sheets step.

## Setup

1. **Apify token.** Apify Console > Settings > API & Integrations. In n8n create a **Header Auth** credential named `Apify API`: Name `Authorization`, Value `Bearer ` followed by your token. Select it in **Run ATS Jobs Scraper**.
2. **Settings.** In **Search settings**, list board URLs or `ats:slug` entries. Greenhouse, Lever, Ashby, Workable, Recruitee, Teamtailor, Polymer and HireHive boards work by URL or slug; Workday needs the full career site URL, for example `https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite`. Keywords match job titles, case-insensitive.
3. **Output folder.** n8n 2.x only lets file nodes write inside the folders in `N8N_RESTRICT_FILE_ACCESS_TO` (default `~/.n8n-files`). The template default `/home/node/.n8n-files` is that folder in the official Docker image. On an npm install, use your own `~/.n8n-files` as a full path, or add a folder to `N8N_RESTRICT_FILE_ACCESS_TO`.
4. Run it once with **Execute workflow**, open the CSV, then activate it.

## Other destinations

You can replace **Convert to CSV** and **Write CSV file** with a Google Sheets, database, email or webhook node. Only the CSV output is tested.

## Cost

The Actor charges $0.002 per job returned. There is no separate start fee in its pricing, and records about boards that could not be resolved are free. `maxUsd` (sent as `maxTotalChargeUsd`) caps each run; the default $0.50 covers 250 jobs. With `onlyNewJobs` on, the first run returns everything that matches and later runs return only jobs not returned before, so a day with 10 new matching jobs costs $0.02. Jobs left out because a run hit the cap are not marked as returned, so the next run picks them up.

## Limits

- The sync endpoint waits up to 300 seconds. A longer run returns HTTP 408 to n8n and keeps running on Apify; list fewer boards per workflow if that happens.
- Use a different `stateStoreName` for each separate search. Two workflows sharing one store name would split the new jobs between them.
- A Job ID is recorded as seen by **Skip jobs already saved** before the file is written. If the write fails (for example, a folder n8n is not allowed to use), those jobs are not offered again; fix the folder and clear the node's history (Remove Duplicates > Clear Deduplication History) if you need them.

## Tests

`tests/run_local_n8n.sh` imports the workflow into a throwaway local n8n (tested with n8n 2.45.4), builds a test copy (manual trigger, a local mock of the Apify endpoint, output to a temp folder) and executes it twice. `tests/check_run.py` asserts the request path, cost cap, auth header and body, that 5 records in (2 jobs, 1 unresolved board, 1 expired job, 1 status message) become 2 rows, that run 1 writes one CSV with those 2 rows, and that run 2 with the same mock data keeps 0 rows and writes no file. No Apify credit is used.

A real-API run of the same workflow (3 executions, real Apify runs) is recorded outside this repo in the n8n library submission notes.
